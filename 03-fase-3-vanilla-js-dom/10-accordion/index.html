Roadmap ini dirancang untuk memandu pembelajaran frontend secara bertahap mulai dari HTML dasar, CSS layouting, hingga manipulasi DOM menggunakan Vanilla JavaScript murni tanpa framework.
Memahami fondasi JavaScript murni sangat krusial sebelum menggunakan framework seperti React atau Vue, agar kamu memahami cara kerja bawaan browser dalam memproses event dan merender DOM.
Ya, seluruh komponen didesain menggunakan pendekatan *responsive design* dan fleksibilitas CSS modern agar nyaman diakses melalui smartphone, tablet, maupun desktop.
