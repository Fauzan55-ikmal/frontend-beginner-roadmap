# Frontend Beginner Roadmap 🚀

Repositori ini berisi kumpulan proyek latihan _Frontend Web Development_ tingkat dasar (_beginner_) yang bersumber dari [roadmap.sh/frontend/projects](https://roadmap.sh/frontend/projects).

Tujuan utama dari repositori ini adalah memperkuat pemahaman fundamental pada web development murni (vanilla), meliputi semantik HTML5, teknik layouting CSS, serta interaktivitas DOM JavaScript.

---

## 🛠️ Kurikulum & Proyek

### 01. Fase 1: Fondasi Semantik HTML & Form

Fokus pada penggunaan tag semantik, elemen formulir, aksesibilitas dasar, dan struktur dokumen tanpa CSS kompleks.

- [ ] `01-blog-post-page` - Halaman postingan blog dengan tag semantik (`<article>`, `<header>`, `<figure>`).
- [ ] `02-contact-form` - Formulir kontak dengan validasi bawaan HTML5 dan aksesibilitas elemen form.
- [ ] `03-pricing-table` - Tabel perbandingan harga menggunakan tag tabel HTML yang terstruktur.

### 02. Fase 2: CSS Layouting, Flexbox, Grid & Positioning

Fokus pada tata letak responsif, Flexbox, CSS Grid, serta positioning elemen UI.

- [ ] `04-testimonial-cards` - Komponen kartu dengan Flexbox, shadow, dan border-radius.
- [ ] `05-image-grid` - Galeri gambar responsif menggunakan CSS Grid.
- [ ] `06-tooltip-ui` - Elemen petunjuk (tooltip) dengan CSS Positioning (`absolute`/`relative`).
- [ ] `07-changelog` - Tampilan timeline vertikal menggunakan penataan spacing dan list styling.

### 03. Fase 3: Logika Vanilla JavaScript & Manipulasi DOM

Fokus pada logika JavaScript murni, event listener, serta manipulasi elemen DOM.

- [ ] `08-restricted-textarea` - Textarea dengan penghitung karakter _real-time_ dan batas maksimal.
- [ ] `09-tabs` - Komponen tab interaktif dengan penambahan/pengurangan kelas CSS via JS.
- [ ] `10-accordion` - Komponen FAQ buka-tutup interaktif.
- [ ] `11-cookie-consent` - Banner persetujuan cookie yang menyimpan status di `localStorage`.
- [ ] `12-age-calculator` - Kalkulator umur menggunakan pengolahan objek `Date`.

---

## 💻 Tech Stack

- **HTML5** (Semantic Markup)
- **CSS3** (Flexbox, CSS Grid, Custom Properties)
- **JavaScript** (ES6+, DOM Manipulation)
